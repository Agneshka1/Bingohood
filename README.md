# Bingohood 
Bingohood is a mobile application for Android designed to encourage users to explore interesting places in Gdańsk by completing a bingo board.
The application allows users to discover the city through a game in which they visit selected locations and mark completed tasks.

# Features
- Bingo board featuring selected locations in Gdańsk.
- Displaying 9 random locations provided by web server each day
- Marking visited places as completed.
- Tracking progress on the bingo board.
- Achievements

## Technologies:
- Kotlin
- Android
- Jetpack Compose
- Gradle

## Getting started
1. Install Android Studio.
2. Clone the project repository or download its contents.
3. Open the project in Android Studio.
4. Wait for Gradle synchronization to complete.
5. Run the application on an Android emulator or a connected device.
