## Collaboration Guidelines for the Bingohood Project

### 1. Work Organization

- Project development is managed using GitHub.
    
- Each team member is responsible for their assigned tasks.
    
- The project manager coordinates the team's work and approves Pull Requests.
    

### 2. Branch Creation

- Each task should be completed on a separate working branch.
    
- Branch names should clearly describe the task being performed.
    
- Changes should not be made directly to the `main` branch.
    

### 3. Commits

- Commits should describe the changes being introduced.
    
- Commit messages should be short and understandable.
    
- Changes should be committed regularly.
    

### 4. Pull Requests

- Once a task is completed, a Pull Request should be created for the main repository.
    
- Each Pull Request should include a title and a description of the changes made.
    
- A link to the related Trello task should be included.
    
- Any issues or limitations should be described in the Pull Request.
    
- Pull Requests are reviewed and merged by the project manager.
    

### 5. Trello

- Project tasks are managed using Trello boards.
    
- Each task should include a description, an assigned team member, and a deadline.
    
- Work progress is tracked by updating the task status.
