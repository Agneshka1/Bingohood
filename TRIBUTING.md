# Contributing to Bingohood

## 1. Work Organization

- Work on the project is carried out using GitHub.
- Each team member is responsible for the tasks assigned to them.
- The project manager coordinates the team's work and approves Pull Requests.

## 2. Creating Branches

- Each task should be developed on a separate working branch.
- Branch names should describe the task being worked on.
- Do not make changes directly to the `main` branch.

## 3. Commits

- Commits should describe the changes being made.
- Commit messages should be short and clear.
- Save your changes regularly.

## 4. Pull Requests

- After completing a task, create a Pull Request to the main repository.
- A Pull Request should include a title and a description of the changes made.
- Include a link to the related task in Trello.
- If there are any problems or limitations, describe them in the Pull Request.
- Pull Requests are reviewed and merged by the project manager.

## 5. Trello

- Project tasks are managed using Trello boards.
- Each task should have a description, an assignee, and a due date.
- Progress is updated by changing the task's status.
